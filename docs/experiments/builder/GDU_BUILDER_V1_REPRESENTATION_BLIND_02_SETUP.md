# Builder V1 表示层盲测 02 设置

## 1. 实验问题

盲测01已经用于发现问题，不能继续充当新版 Builder 的主要泛化证据。盲测02回答：

> 命题状态、表格证据位置、数值规范化和三类比较结构，能否处理模型未见过的表达？

## 2. 预先冻结

远程生成前已冻结：

- 4个案例；
- 11个 Evidence Block；
- 13个允许 Atom 和对应 Gold；
- 请求结构与模型输出 Schema；
- 单次运行最多一个远程请求。

输入、Gold 和最终请求均有独立 SHA-256。模型请求中没有 Gold，也没有 Evidence Block 之外的布局提示。

## 3. 案例分层

### 3.1 来源案例

- PGKD算法片段：检查算法字面对象能否保持，不静默修复论文索引；
- GB 45438-2025元数据与附录：检查跨页引用和规范力。

### 3.2 控制案例

- 财务控制表：使用已核实数值重新排成带表头、单位和行列位置的冻结表格；
- 比较控制文本：覆盖固定阈值、对象间比较、集合最值和来源明确的未判定状态。

两类成绩分别解释。控制案例用于隔离机制错误，来源案例用于观察真实材料上的表现。

## 4. 判读原则

- 首先报告原始严格匹配，不事后覆盖；
- 再区分内容遗漏、模型结构错误、校验器误伤和Gold问题；
- 不把盲测01的离线重放提升当作盲测02成绩；
- 只有未见表达上的问题族错误减少，才能说明本轮修改具有泛化价值。
