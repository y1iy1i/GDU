# Builder V1 表示层盲抽取实验 01 结果报告

## 1. 实验结果

2026-08-21，`deepseek-v4-flash-0731` 完成了一次三领域受约束盲抽取。模型在一次远程请求中读取财务、PGKD 论文和 GB 45438-2025 的冻结 Evidence Block，没有读取 Gold。

原始机械评分为：

| 指标 | 结果 |
|---|---:|
| 模型提交候选 | 14 |
| 通过确定性校验 | 8 |
| 精确结构匹配 | 7 |
| 精确率 | 50.0% |
| 召回率 | 50.0% |
| 校验接受率 | 57.14% |
| 多余 Atom | 0 |

上述 50% 不能直接解释为“模型只理解了一半”。它同时包含模型结构错误、校验器边界错误和一处 Gold 极性错误。

## 2. 内容发现与结构编译必须分开评价

模型提交的 14 条自然语言陈述都能在原文中找到支持。但第一条 2025 年金额候选错用了 `finance_2024_ocf_amount`，与第二条重复。

因此：

- 原文内容发现：14/14 条陈述有原文依据；
- 唯一 Atom 覆盖：13/14，即 92.86%；
- 原始精确结构匹配：7/14，即 50%。

这说明首轮的主要瓶颈不是“没看见原文内容”，而是将内容稳定编译成统一逻辑字段。

## 3. 按领域审计

### 3.1 财务：0/4 原始精确匹配

#### 2025 年金额

- 陈述和金额正确；
- Atom 错写为 2024 年 Atom；
- `2025` 来自请求中的表格布局说明，但该说明没有进入 Evidence Block，因此校验器又报了数字无来源。

这同时包含一个模型 Atom 映射错误和一个实验证据边界错误。

#### 2024 年金额

- Atom、金额、Context 和量值均正确；
- 仅因 `2024` 在布局说明而不在 Evidence Block 中被拒绝。

这是一条确定的校验器/输入边界误伤。排除该误伤后，精确结构匹配应至少为 8/14（57.14%），而不是 7/14。

#### 同比变动

- 数值 `-55.06` 和 percent 单位的语义正确；
- 原文数据块只含 `-55.06`，单位 `%` 位于布局说明，导致字面子串校验误拒；
- 模型把负数的符号当成了 Claim 的负极性。

原 Gold 也把该 Claim 标为 `negative`，这与当前“极性作用于顶层命题真值”的定义冲突。正确表示应是：

```text
Claim polarity = positive
Quantity normalized_value = -55.06
```

原 `gold.json` 不被覆盖，修正记录单独保存在 `gold_adjudication_v1.json`。

#### 变化原因

模型因为原因内部出现“减少”，将顶层命题标为 `negative`。但顶层命题实际上在肯定“变化原因是销售收现减少”，因此应为 `positive`。这是否定作用域问题，不是财务领域专用错误。

### 3.2 PGKD：3/4 原始精确匹配

验证样本不泄露、使用早停和生成下一轮数据三条全部通过。

“返回验证损失最低的模型”内容正确，但模型将 `lowest` 写成需要数值 Quantity 的固定阈值约束。这暴露了当前 `ComparisonConstraint` 只覆盖数值阈值，尚未区分：

- 固定阈值：不少于2秒；
- 相对比较：低于上一年；
- 最高/最低值：候选模型中验证损失最低。

这是一个应扩展为比较问题族的结构缺口，不应只为 `lowest` 添加特例。

### 3.3 GB 45438-2025：4/6 原始精确匹配

起始位置义务、末尾/中间位置许可、边或角义务、字型可辨义务全部正确。

高度和时长两条具有相同的问题族：

- 模型正确识别了 `gte`、`5%` 和 `2s`；
- 但将“不应低于/不应少于”标为 `negative + prohibition`；
- 当前规范表示要求将其写为 `positive + obligation + gte`；
- 模型将 Constraint threshold 写成“画面最短边长度的5%”和 `2s`，而契约要求它与 Quantity normalized value `5` 和 `2` 完全一致。

前两项是模型对规范力和否定作用域的实质错误。最后一项也暴露了请求契约没有把“threshold 必须等于 normalized_value”说得足够明确。

## 4. 问题族结论

首轮不应产生七个句子级补丁，而应形成四个一般问题族：

1. **顶层极性与局部负值/否定分离**：负数、原因内的“减少”和规范词内的“不”不自动决定 Claim polarity。
2. **布局与表头也必须进入证据边界**：年度、币种、单位和列口径不能只作为提示词传给模型。
3. **数值保真应比较规范值和单位**：不应要求命题中的 `-55.06%` 必须作为一个连续子串出现在表格数据块。
4. **比较需要区分阈值、相对值和最值**：不能用“threshold + Quantity”处理所有比较语义。

## 5. 对 Builder 的当前判断

本轮支持以下中间结论：

- 小模型能在三领域小样本中稳定找到大部分目标内容；
- Evidence Quote、Context、Atom 词表和隔离校验的整体方向可行；
- 当前还不能宣称 Representation Compiler 已可用，因为作用域和比较标准化仍会产生高影响结构错误；
- 校验器确实阻止了错误结构进入正式 GDU，但同时存在至少一条确定误伤。

下一轮不更换模型，而是先修正上述四个问题族，然后使用同一文档的新冻结变体运行第二轮，避免对已见原句进行直接调参。
