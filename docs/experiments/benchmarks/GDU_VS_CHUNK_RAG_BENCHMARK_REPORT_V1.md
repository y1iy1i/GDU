# GDU 与 Chunk-RAG 对照实验报告 v1

> 日期：2026-08-20  
> 结论：GDU 显示出特定价值，但本轮未证明总体优于普通 Chunk-RAG。

## 1. 实验设置

实验严格使用运行前已推送的 `GDU_VS_CHUNK_RAG_BENCHMARK_PLAN_V1.md`：同一篇 237 页年报、同一组六题、同一回答模型 `deepseek-v4-flash-0731`、温度 0、每题约 7,200 字符上下文。

- A 组：从 237 个物理页文本块中检索；
- B 组：从冻结 GDU 的 18 个结构块中检索；
- 每组一次批量 API 调用；
- 模型只看到匿名条件 A/B，没有看到 Gold 与评分规则。

## 2. 预注册评分结果

| 问题 | Chunk-RAG | GDU-RAG | 主要差异 |
|---|---:|---:|---|
| Q1 双主业主线 | 2 | 2 | 两组都恢复算力增长、制造仍亏与地位不对称。 |
| Q2 毛利率口径 | 2 | 2 | 两组都恢复净额法、49.69% 与还原后 10.09% 的边界。 |
| Q3 现金流质量 | 1 | 2 | 两组都提到应收/信用风险；只有 GDU 进一步取回大额相向订金流量。 |
| Q4 客户集中张力 | 1 | 1 | 两组都漏掉“不严重依赖少数客户”的模板勾选；GDU 还把无重大诉讼/违规担保误当成表面张力的另一端。 |
| Q5 未来收益边界 | 2 | 1 | Chunk-RAG 恢复披露日 38,000P、36 个月以上合同陈述及风险；GDU 只恢复风险和前瞻边界。 |
| Q6 内部冲突 | 0 | 1 | GDU 恢复分红表格 0 元与正文 3.70 元冲突；两组都未恢复预注册的模板勾选—叙述张力。 |
| **总分** | **8/12** | **9/12** | **差 1 分** |

按预注册判定规则，总分差 1 分属于“未证明优势”；Q4–Q6 中 GDU 仅在 Q6 更高，Q5 反而更低，也不满足跨章节/冲突题至少两题更高的条件。

## 3. GDU 已经表现出的价值

GDU 不是没有用。它在普通关键词检索容易遗漏的两类任务上提供了真实增益：

1. 保留跨页关系：经营现金流净额改善与大额相向订金流量能够同时进入回答；
2. 保留未消解冲突：分红表格“0 元”与正文“3.70 元”没有被静默选边或合并。

横向 CP1 实验还表明，章节主干可以继续扩展；把模型判断与程序化证据绑定分开后，结构和证据均能通过严格验证。

## 4. 当前缺点与成本

1. **上游漏检会固化为下游盲点。** 冻结 GDU 没有保存客户集中模板张力和长期合同陈述，回答模型因此无法恢复；结构化知识不是自动完整的真相。
2. **复杂字段输出不稳定。** DeepSeek 在 CP2、CP4 和横向 CP1 中多次理解正确但格式或引用错误，需要定向修正或确定性代码接管。
3. **构建成本明显高于直接分块。** Chunk-RAG 几乎可直接建立索引；GDU 需要结构、语义、关系、计划、停止门与验证。当前完整冻结 GDU 还来自更强的 `gpt-5.6-sol/high` Builder，而回答对照使用 DeepSeek；即使有这项前期投入，总分也只高 1 分。
4. **本实验范围有限。** 只有一篇中文上市公司年报、六个复杂问题和一个简单字符 n-gram 分块基线，不能外推到所有文档或所有先进 RAG/PageIndex 系统。

## 5. 当前研究判定

### 是否好用

- 作为“保留关系、冲突、不确定性并可追溯生成”的研究型知识表示：**有用，值得继续研究**；
- 作为已经证明优于现有知识库的通用方案：**没有证明**；
- 作为可直接替换 Chunk-RAG 的低成本生产系统：**目前不够好用**。

因此当前决策是：**研究继续，优越性声明暂停，生产替换暂缓。**

## 6. 下一轮只解决的两个问题

不增加顶层层数，保持四层主干，只处理两个已由实验定位的瓶颈：

1. 提高 Builder 对模板勾选—叙述张力、合同时间点等高影响证据的召回；
2. 将证据摘录、哈希和引用绑定全部交给确定性代码，让模型只负责语义判断。

完成后应使用新的未调参文档，对更强的 Chunk-RAG 或 PageIndex 基线复验；在此之前不再通过增加规则数量制造表面复杂度。
