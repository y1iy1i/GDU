# GDU 与 Chunk-RAG 对照实验计划 v1

> 状态：运行前预注册  
> 日期：2026-08-20

## 1. 研究问题

在同一篇 237 页中文年报、同一组问题、同一回答模型和相近上下文预算下，GDU 结构化知识是否比普通文本分块检索更能保留跨章节关系、口径限制、冲突与不确定性？

本实验只比较这两个具体实现，不代表 GDU 与所有知识库、所有 RAG 或 PageIndex 的全面比较。

## 2. 固定条件

- 来源：冻结的利通电子 2025 年年度报告；
- GDU：Pilot 03 已冻结的盲构建 `BUILDER_OUTPUT.md`；
- 回答模型：`deepseek-v4-flash-0731`，关闭思考，温度 0；
- 每组一次批量调用，共两次；
- 每个问题各自检索，文本预算相同；
- 两组使用完全相同的问题和回答 JSON Schema；
- 回答模型不得使用外部知识，不得看到 Gold 或评分条件；
- 组名在请求中记为 A/B，不告诉模型哪组是 GDU。

## 3. 两个条件

### A：普通 Chunk-RAG

将 `paper.txt` 按物理页和固定长度切块，用问题字符 n-gram 的确定性相似度检索。返回原文块及物理页号，不提供人工关系。

### B：GDU-RAG

将冻结的 `BUILDER_OUTPUT.md` 按标题、表格行和固定长度切块，用同一检索算法和同一字符预算检索。返回语义单元、原子判断、关系、计划与证据索引中的原文结构化表示。

## 4. 固定问题

1. 公司 2025 年经营变化的核心主线是什么？两项主业是否同等成熟、同等盈利？
2. 报告中的算力业务 49.69% 毛利率能否直接理解为总额经济口径下的盈利率？
3. 经营现金流大幅增长是否足以说明经营质量已经没有问题？还要结合什么？
4. 报告对客户集中度有哪些看似不一致的表述？应该如何同时理解？
5. 算力业务快速增长是否意味着未来收益已获保证？请结合时间点、合同陈述和经营风险回答。
6. 报告内部有哪些不能被系统静默合并的表格、勾选项或叙述冲突／口径张力？

## 5. 运行前评分项

每题 0–2 分：关键含义完整且边界正确为 2；方向正确但遗漏重要关系或边界为 1；未回答、冲突或高影响过度推断为 0。总分 12。

- Q1：必须同时保留“双主业”、算力为增长/盈利引擎、制造仍亏损或尚未扭亏，以及二者不对称；
- Q2：必须保留 49.69% 表面口径、净额法、还原总额后综合约 10.09%，并拒绝直接等同；
- Q3：必须保留现金流净额改善，同时至少连接应收/信用减值与大额相向订金流量两个限制中的一个；两个均有才可得 2 分；
- Q4：必须连接前五客户/应收集中数据、无单一客户超过 50%或“不严重依赖”模板表述、风险章节“客户集中度高”，并说明口径不同而非强行判错；
- Q5：必须区分披露日 38,000P 与 2025 年末，保留长期合同覆盖投资回报属于管理层陈述，并以需求、竞争、GPU、融资或集中度风险限制“未来保证”；
- Q6：2 分要求至少恢复分红 0 元与 3.70 元冲突，并恢复两组模板张力中的至少一组；只恢复分红冲突或只泛称口径差异得 1 分。

任何凭空补充来源外事实、把风险说成已发生危机、把关键审计事项说成已发现造假，均视影响将对应题降为 0。

## 6. 判定规则

- GDU 总分高至少 2 分，且在跨章节/冲突题 Q4–Q6 中至少两题更高：记为本任务上的明显优势；
- 总分差 1 分以内：记为未证明优势；
- GDU 总分更低，或产生基线没有的高影响错误：记为本任务上的劣势；
- 无论得分如何，都另外记录检索上下文长度、API 次数、构建成本和系统复杂度，不用答案质量掩盖成本。
