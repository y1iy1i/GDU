# 最小 GDU 外部复验 01 计划

> 状态：来源下载与阅读前冻结  
> 日期：2026-08-20

## 1. 来源选择规则

为避免根据文档内容挑选容易成功的样本，本轮使用以下确定性规则：

1. 与 Pilot 03 相同，选择上海证券交易所 A 股上市公司 2025 年完整年度报告；
2. 从利通电子证券代码 `603629` 向上选择第一个已公开完整 2025 年年度报告的证券代码；
3. 搜索确认 `603630` 拉芳家化已于 2026-04-28 披露完整 2025 年年度报告，因此停止继续寻找；
4. 只使用上交所正式 PDF，不使用搜索摘要、媒体解读、行情网站总结或公司外部信息作为内容证据。

正式来源：

- 公司：拉芳家化股份有限公司；
- 证券代码：603630；
- 文档：2025 年年度报告；
- 上交所 PDF：`https://static.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-04-28/603630_20260428_NK0X.pdf`。

搜索仅用于确认文件存在和取得正式 URL。搜索结果页面曾显示报告页数和一段自动摘要，因此后续 Builder 请求不得包含搜索结果；Gold 与评价只允许回到正式 PDF。

## 2. 研究问题

复验上一轮消融结果：判断节点与确定性证据能否以明显小于原文的表示规模，至少保持 Raw Chunk 的答案质量；显式关系是否有必要常驻。

## 3. 三个条件

- V0：Raw Chunk；
- V2：判断节点＋证据；
- V2R：V2 基础上，针对每个问题临时并行计算候选关系，不把全部关系永久保存。

不重新运行 Chunk+Structure 和 Full GDU，因为上一轮没有证据支持它们是最小核心。

## 4. 通用问题

问题保持跨公司通用，不使用利通电子或拉芳家化的专有答案：

1. 报告期经营变化的核心主线是什么？不同业务、品牌或渠道的表现是否一致？
2. 利润变化由哪些经营性与非经常性因素共同造成？不能把哪些因素混为一谈？
3. 经营现金流与利润是否指向相同的经营质量结论？还需结合哪些资产、减值或周转信息？
4. 客户、渠道、品牌或供应商集中度披露与风险叙述之间有什么关系或口径边界？
5. 管理层未来计划是否代表未来业绩已经得到保证？主要限制条件是什么？
6. 报告中是否存在必须并列保留的表格、勾选项、时间点或叙述张力？没有充分证据时不得强行制造冲突。

## 5. 实验顺序

1. 下载正式 PDF，记录哈希并确定性提取逐页文本；
2. 仅依据 PDF 建立最小评价 Gold 并冻结；
3. Raw Chunk 直接运行；
4. Minimal Builder 只读取 PDF 文本包，生成判断候选，程序绑定证据；
5. V2 运行；
6. V2R 只对问题相关候选节点生成临时关系并运行；
7. 依据冻结 Gold 评分并比较表示大小、调用次数和失败率。

## 6. 停止与成本边界

- API 额度错误、余额不足或供应商拒绝时立即停止，不自动续费；
- 每个回答条件最多一次调用；
- Minimal Builder 优先一次生成，最多一次格式纠正；
- 不因结果不理想更换文档、问题或 Gold；
- 本轮可以形成架构方向判断，但两篇年报仍不足以证明跨领域普遍性。
