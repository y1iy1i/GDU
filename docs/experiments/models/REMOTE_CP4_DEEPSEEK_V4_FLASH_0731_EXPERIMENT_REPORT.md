日期：2026-08-20

状态：两次有界定向修正后通过；尚未进入 CP5。

## 实验简介

CP4 测试 GDU 是否能从“对象集合”发展为“可验证的关系网络”。本轮不允许新增事实或解释，只连接 CP2、CP3 已接受的断言。

预登记网络包含一条组成关系、两条支持关系和两条限定关系。并行解释仍由 CP3 的 interpretation group 表达，不使用 `alternative_to` 将两个可同时成立的解释误写成互斥关系。

- 模型：`deepseek-v4-flash-0731`；
- 输入：CP3 已接受对象，以及年报物理页 9–12；
- 阶段：CP4，只允许 relation；
- 每次运行最大调用次数：1；
- 实际 API 请求：3 次；

- 定向修正：2 次，达到 Builder 允许上限。

## 预登记关系

1. `A-003 → A-001 / composes`：非经常性损益参与构成归母净利润与扣非净利润的差额；

## 结果解读

本轮结果把事实、解释和不确定性连接成了一个小型有向网络：来源断言支持两个并行解释，不确定性约束又限制两个解释被夸大；利润口径之间还保存了组成关系。GDU 因而不再只是五张独立卡片，而能表达“为什么支持”和“支持到什么边界”。

模型依然表现出复杂结构不稳定：前两次分别漏掉内部条件字段和候选外层字段。CP4 的成功依赖两次定向修正，不能声称一次生成稳定可靠。

最终 `R-001` 的自然语言理由提到“第10–11页”，而结构化证据引用为第 9、11 页。关系本身由第 9 页利润金额和第 11 页非经常性损益合计充分支持，因此未改变验收结论；后续提示已增加“不得提及未由 E-reference 覆盖的页面”。

## 当前结论边界

可以得出：在预登记边集合和两次有界修正内，模型能够生成方向、类型、认识来源和证据均合格的局部关系网络。

不能得出：模型能够自由发现整篇年报的全部重要关系，能够稳定一次生成，或当前网络已足以支持完整文档问答。
