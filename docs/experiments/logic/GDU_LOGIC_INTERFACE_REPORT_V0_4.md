# GDU 候选逻辑接口调试报告 v0.4

> 日期：2026-08-20  
> 本轮问题：TMS局部重算能否与完整重算得到相同结果  
> 结论：在当前无推理环、正向依赖的最小图中等价；替代支持和下游Dung标签均保持一致。

## 1. 局部重算风险

若A和B都能独立推出M：

```text
A → M → C
B → M → C
```

A失效时，只沿A向下删除会错误撤销M和C。正确算法必须同时找到M的其他生产者B路径。

## 2. 受影响闭包

v0.4采用以下闭包规则：

1. 失效Claim进入受影响集合；
2. 使用受影响Claim作为前提的Inference进入受影响集合；
3. 这些Inference的结论进入受影响集合；
4. 一个Claim受影响后，所有能够产生该Claim的替代Inference也进入重算集合；
5. 重复以上过程，直到集合不再变化；
6. 未进入闭包的节点沿用原有效状态；
7. 闭包内部按照推理拓扑顺序重新计算。

第4条是保持替代支持的关键。

## 3. 实验图

实验包含：

```text
A ─I-A→ M ─I-FINAL→ C
B ─I-B→ M

S ─I-SIDE→ SIDE
```

其中SIDE是与A、B分支无关的对照路径。

### A失效

结果：

- `I-A`失效；
- `I-B`仍有效；
- M与C继续有效；
- SIDE没有进入受影响闭包；
- 局部重算与全图重算一致。

### A和B同时失效

结果：

- `I-A`和`I-B`均失效；
- M和C失效；
- SIDE继续有效；
- 局部重算与全图重算一致。

## 4. 等价检查范围

对三个种子Claim的所有非空失效组合进行了比较。每组同时检查：

- 有效Claim集合；
- 有效Inference集合；
- 编译后的StructuredArgument ID；
- attack边；
- Dung grounded标签。

所有比较一致。

## 5. 重要实现边界

本轮证明范围仅限于：

- 无Inference依赖环；
- 单调的正向前提依赖；
- 节点失效，不包含规则优先级改变；
- grounded semantics；
- 当前最小Context和Attack模型。

尚未证明：

- 含默认否定或“缺少证据”前提的非单调规则；
- Preference变化导致的全局攻击结果变化；
- 大图上的局部重算复杂度收益；
- 新增节点与删除节点同时发生；
- 多个Context投影规则联动变化。

因此不能把本轮结果外推为任意非单调论证图都可以安全局部更新。

## 6. 当前判断

三项首轮接口缺陷现已分别得到最小解决：

1. 多条独立推导路径能够无损保留；
2. Context不对齐时不能直接rebut；
3. 当前受限图上的TMS局部重算与全量结果一致。

这意味着“三层逻辑主干＋两个横向模块”已经通过第一轮最小兼容性调试，但尚未完成真实文档级验证。下一步不应继续添加关系，而应把拉芳年报中的一个真实推理片段完整映射到该结构，检查自然语言内容进入这套逻辑后是否仍然可表达、可计算和可追溯。
