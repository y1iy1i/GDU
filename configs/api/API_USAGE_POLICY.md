# GDU Adapter v1 外部 API 使用规则

日期：2026-08-20

状态：实验约束，尚未冻结。

## 大白话

实验允许使用用户指定的外部模型 API。GDU 代码可以消耗账户中已经存在的 API 余额，但不会充值、购买余额、开通订阅或自动续费；Key 缺失、余额不足或服务拒绝请求时立即停止。

## 机械规则

1. 外部 API 必须由用户指定提供商和模型。
2. API Key 只能从环境变量读取，不写入仓库、请求正文、日志或错误消息。
3. 每轮实验必须锁定配置 SHA-256 和最大调用次数；默认请求权限仍为关闭。
4. 只有启用配置、当次显式授权和 Adapter 请求许可同时成立时才能调用。
5. HTTP、鉴权、额度或响应格式失败均转为技术失败，不自动切换模型或提供商。
6. 本项目没有充值、购买余额、开通订阅或自动续费的代码入口。

## 当前选择

- 提供商：阿里云百炼北京区 Token Plan；
- 模型：`qwen3.7-plus`；
- Base URL：`https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；
- Key 环境变量：`DASHSCOPE_API_KEY`；
- JSON 模式：`native`，由接口保证 JSON 格式，再在本地按 Schema 严格验证；
- 首轮最大调用次数：1；
- 当前状态：最小连接测试成功 1 次；后续调用必须重新明确授权和次数上限。
