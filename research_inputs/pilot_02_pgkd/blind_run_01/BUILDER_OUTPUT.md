## 6. 五问式 GenerativePlan

### 6.1 为什么生成这篇论文？

作者试图解决“LLM 分类能力强，但生产推理昂贵、慢且输出难工程化”的矛盾（A-001），并把目标设为只在训练期使用 LLM、部署满足 SLA 的小模型（A-002）。相关工作对工业式多类别、可获得约千条标注数据的场景覆盖不足（A-003；R-001）。

### 6.2 论文要生成的核心意义是什么？

核心提案是 PGKD：让教师循环接收学生的总体逐类表现与高信息误差，再生成下一轮数据，形成 performance-aware 的黑盒蒸馏（A-004、A-005、A-007；R-011、R-012）。预期意义不是让 LLM 直接推理，而是把训练期教师能力转成小模型的分类性能与部署效率（A-002、R-008）。

### 6.3 为支撑核心意义选择了什么内容？

论文选择了：既有 KD 缺口（U-003）；三项机制与循环算法（U-004、U-005）；四个 4–335 类数据集和固定师生配置（A-011、A-012）；主性能、样本规模、文献比较、消融及效率基准（U-007–U-011）；最后用限制、伦理和完整提示模板限定/支持解释（U-013、U-015）。所有计划事实来自上述对象，不另建事实源。

### 6.4 内容如何组织成论证？

组织链为：生产问题 → 既有方法缺口（R-001）→ 三机制响应（R-002）→ 算法/提示操作化（R-003、R-004）→ 固定实验设计与主结果（R-005）→ 样本规模和消融提供边界与机制证据（R-006、R-007）→ 推理基准回应部署动机（R-008）→ 限制与伦理约束外推（R-009、R-010）。

### 6.5 结论必须受哪些约束？

- 方法层：早停文字与伪代码不一致（A-009；R-021），生成配置也不完整（A-041；R-028）。
- 效果层：类别数解释有数据集/基线余量替代解释（A-015；R-014）；“不退化”只限报告网格（A-019；R-015）。
- 比较层：Table 3 和 SOTA 行预算/任务口径不等价，且正文遗漏 AMZN macro-F1 的明显劣势（A-021、A-039、A-043；R-016、R-025、R-029）。
- 统计层：未报告显著性检验，消融证据只宜作方向性解释（A-024、A-036；R-018）。
- 验证层：不传原始验证样本不等于排除自适应验证过拟合（A-035；R-022）。
- 效率层：25× 成本表述与表 5 不可直接对齐，且未计蒸馏训练成本（A-027、A-037；R-020、R-023）。
- 泛化层：教师/学生、语言、任务与真实生产环境均有限；语言生成是未验证扩展（A-028、A-030、A-033、A-034）。
- 风险层：教师偏差或幻觉可能进入并放大学生（A-031；R-026）。

### 高影响竞争解释保留

1. **增益随类别数扩大**：主要解释为多类别稀疏任务更受益（A-014）；替代解释为跨数据集难度、基线余量等混杂（A-015）。来源不足以淘汰替代解释。
2. **组件贡献**：主要解释为验证报告与难负例分别有效（A-023）；替代解释为部分小差异可能落入随机波动，因消融无方差/显著性检验（A-024）。方向性发现保留，强因果量化不保留。
3. **验证过拟合**：作者解释为不泄露原始验证样本可缓解（A-006）；替代解释为逐轮指标反馈仍构成自适应使用（A-035）。两者并列，不合并成“已消除”。
4. **生产经济性**：主要解释为推理端显著更快且单批成本低（A-025、A-026）；替代解释为训练期教师调用可能改变生命周期经济性（A-029、A-037）。
